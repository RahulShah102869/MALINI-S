# 🍽️ MALINI'S – Fine & Dine Restaurant Website

Welcome to the **MALINI'S** project! 👋

This project is a modern and responsive restaurant website developed for MALINI'S Fine & Dine Restaurant. The goal is to create a professional online presence, showcase the restaurant, and improve customer engagement through an attractive and user-friendly design.

## 🌐 Live Demo

🔗 **Website:** [Visit MALINI'S](https://malinis-restaurant.netlify.app)

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling, layout, and responsive design
- **JavaScript** – Interactive features
- **Git & GitHub** – Version control and project management

## ✨ Features

- Modern and attractive restaurant website design
- Responsive layout for different screen sizes
- User-friendly navigation
- Restaurant information and presentation
- Interactive website elements
- Clean and organized user interface
